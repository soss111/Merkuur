Google'i sisselogimine pole veel ühendatud

Server vajab Google Cloud OAuth kliendi ID-d. Salasõna ei ole vaja, ainult avalik kliendi ID.

  1. Ava Google Cloud Console → Credentials.
  2. Loo OAuth client, tüüp Web application.
  3. Lisa lubatud JavaScripti päritolu: https://www.merkuur.eu ja testimiseks http://localhost:8787.
  4. Kirjuta kliendi ID faili data/admin.config.json väljale googleClientId.
  5. Vaikimisi on lubatud info@merkuur.eu. Esimene õnnestunud Google'i sisselogimine lisatakse samuti halduriks, seejärel uks sulgub.
  6. Käivita server uuesti käsuga node server.js ja ava /admin.
